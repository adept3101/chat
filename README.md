## Usage
Welcome to my tcp-chat.
Written in C using POSIX threads and sockets.
Client and server functionality, including a logging system, has been implemented.
Building with Makefile

## Quick start (Linux or macOS only)
```
git clone https://github.com/adept3101/chat
cd chat
make
```
